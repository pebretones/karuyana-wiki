# Karuyana people - Wikipedia (fictional)

A fictional Wikipedia-style page in English about the **Karuyana people**, a fictional Melanesian tribe of the Telahari Highlands. Built as a single static HTML page, ready for GitHub Pages.

## Contents

- `index.html`: the full article, with infobox, custom SVG flag, table of contents, demographics, economy (salt industry), political system (Council of Great Men), culture, and references.

## How to view locally

Just open `index.html` in any modern browser. No build, no dependencies.

## How to publish on GitHub Pages

1. Create a new public repository on GitHub (e.g. `karuyana-wiki`).
2. Upload `index.html` and `README.md` to the repository (or push from this folder).
3. In the repository settings, open **Pages**, set the source to `main` branch and the folder to `/ (root)`.
4. Wait one or two minutes; the page will be live at `https://<your-username>.github.io/karuyana-wiki/`.

## Notes

This page is a creative exercise based on the slide deck *The Secret of the Tribe* by Amaury Fontaine, Paul-Emile Bretones, and Wulfran Clarke-De-Dromantin. The Karuyana, the Telahari Highlands, and all named persons, institutions, and references are fictional.
